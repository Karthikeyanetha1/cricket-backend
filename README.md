## 🚀 Getting Started

### ✅ Prerequisites

```bash
node  >= 18.0.0
npm   >= 9.0.0
MongoDB Atlas account  →  mongodb.com/cloud/atlas (free)
```

### 📥 Clone Repos

```bash
# Backend
git clone https://github.com/Karthikeyanetha1/cricket-backend.git
cd cricket-backend

# Frontend (open new terminal)
git clone https://github.com/Karthikeyanetha1/cricket-frontend.git
cd cricket-frontend
```

### ⚙️ Backend Setup

```bash
cd cricket-backend
npm install
nano .env
```

```env
# Server
PORT=5000

# Database
MONGO_URI=mongodb+srv://youruser:yourpass@cluster.mongodb.net/boxcricket

# Admin
ADMIN_KEY=your_super_secret_admin_key
```

```bash
node server.js

# ✅ Expected output:
# 🚀 Server on port 5000
# 🟢 MongoDB Connected
```

### ⚛️ Frontend Setup

```bash
cd cricket-frontend
npm install
nano .env
```

```env
REACT_APP_API_URL=http://localhost:5000
```

```bash
npm start
# ✅ Opens at http://localhost:3000
```

## 📡 API Reference

### 🌐 Public Endpoints

| Method | Endpoint | Description |
|:------:|----------|-------------|
| `GET` | `/health` | ✅ Server health check |
| `GET` | `/bookings` | 📋 Get all bookings |
| `POST` | `/bookings` | ➕ Create new booking |

#### `POST /bookings` — Request Body
```json
{
  "name": "Karthik",
  "mobile": "9876543210",
  "date": "2026-03-25",
  "startTime": "18:00",
  "endTime": "19:30"
}
```

#### `POST /bookings` — Success Response `201`
```json
{
  "message": "Booking successful",
  "booking": {
    "_id": "65f1a2b3c4d5e6f7a8b9c0d1",
    "name": "Karthik",
    "mobile": "9876543210",
    "date": "2026-03-25",
    "startTime": "18:00",
    "endTime": "19:30",
    "createdAt": "2026-03-21T12:00:00.000Z"
  }
}
```

#### Error Responses
```json
{ "error": "All fields required" }
{ "error": "Invalid mobile number" }
{ "error": "Cannot book past dates" }
{ "error": "Slot conflicts with existing booking (18:00–19:00)" }
```

### 🔐 Admin Endpoints

> Require header: `x-admin-key: your_admin_key`

| Method | Endpoint | Description |
|:------:|----------|-------------|
| `GET` | `/admin/bookings` | 📋 All bookings |
| `PUT` | `/admin/bookings/:id` | ✏️ Update booking |
| `DELETE` | `/admin/bookings/:id` | 🗑️ Delete booking |

#### Test with curl
```bash
# Health check
curl https://your-backend.onrender.com/health

# Get bookings
curl https://your-backend.onrender.com/bookings

# Create booking
curl -X POST https://your-backend.onrender.com/bookings \
  -H "Content-Type: application/json" \
  -d '{"name":"Test","mobile":"9876543210","date":"2026-03-25","startTime":"18:00","endTime":"19:00"}'

# Admin - all bookings
curl -H "x-admin-key: yourkey" https://your-backend.onrender.com/admin/bookings

# Admin - delete
curl -X DELETE -H "x-admin-key: yourkey" \
  https://your-backend.onrender.com/admin/bookings/BOOKING_ID
```

## ☁️ Deployment Guide

### 🚀 Backend → Render

```
1. Push code to GitHub

2. render.com → New Web Service
   Connect → cricket-backend repo

3. Build Command:  npm install
   Start Command:  node server.js

4. Environment Variables:
   PORT       = 10000
   MONGO_URI  = mongodb+srv://...
   ADMIN_KEY  = your_secret_key

5. Deploy → get URL:
   https://cricket-backend-xxxx.onrender.com ✅
```

### 🌐 Frontend → Render

```
1. Update .env:
   REACT_APP_API_URL=https://cricket-backend-xxxx.onrender.com

2. Push to GitHub

3. render.com → New Static Site
   Connect → cricket-frontend repo

4. Build Command:  npm run build
   Publish Dir:    build

5. Environment:
   REACT_APP_API_URL = https://cricket-backend-xxxx.onrender.com

6. Deploy! 🎉
```

### 😴 Prevent Free Tier Sleep

```
uptimerobot.com → New Monitor
URL:       https://cricket-backend-xxxx.onrender.com/health
Interval:  5 minutes
→ Keeps server awake 24/7 for free ✅
```

## 🛡️ Security

```
✅  Helmet.js          →  Secure HTTP headers
✅  Rate Limiting       →  30 requests/min per IP
✅  Admin Auth          →  Secret key on all admin routes
✅  Input Validation    →  Mobile regex, date, time checks
✅  Conflict Detection  →  Overlap prevention in MongoDB
✅  .gitignore          →  .env never pushed to GitHub
✅  CORS Protection     →  Lock to your domain
```
